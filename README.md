1. С какого индекса начинается нумерация элементов массива?
С индекса 0.

2. Какой последний допустимый индекс у массива длиной Length?
Length - 1.

3. Почему в цикле пишут i < array.Length, а не i <= array.Length?
Потому что индекс array.Length выходит за границы массива.

4. Когда удобнее использовать for, а когда foreach?
for  когда нужен индекс элемента. foreach когда нужно просто перебрать все элементы.

5. Почему изменение элемента массива внутри метода видно снаружи без ref?
Потому что массив ссылочный тип, и метод получает копию ссылки на тот же массив.

6. Почему при поиске максимума и минимума удобно начинать с array[0], а не с 0?
Потому что первый элемент может быть отрицательным. Если начать с нуля, максимум или минимум можно найти неправильно.

7. Что означает запись int[] numbers = [1, 2, 3] и чем она отличается от старого варианта int[] numbers = { 1, 2, 3 }?

Обе записи создают массив целых чисел из трёх элементов. Квадратные скобки [1, 2, 3] — современный синтаксис, а фигурные { 1, 2, 3 } — старый синтаксис.
